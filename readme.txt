◆ はじめに
本ソフト「ツナグ先生」をお買い上げ（ダウンロード）いただきありがとうございます。
本ソフトは、日々のお子さんの観察メモ・スタンプ記録から、通知表や指導要録の「所見文案」および「保護者面談カルテ」をAI（Google Gemini）を活用して自動作成・校正・一括管理できる統合校務支援システムです。

------------------------------------------------------------------------
◆ ファイル構成
------------------------------------------------------------------------
・ツナグ先生.exe    : アプリケーション起動用実行ファイル
・readme.txt         : 本ファイル（取扱説明書・利用規約）
・_internal/         : システム実行用ライブラリフォルダ（※削除厳禁）
・app.py             : アプリ実行スクリプト（※削除厳禁）

------------------------------------------------------------------------
◆ 起動方法・使い方
------------------------------------------------------------------------
1. ダウンロードした Zip ファイルを右クリックし、「すべて展開」で解凍します。
2. 解凍されたフォルダ内にある「ツナグ先生.exe」をダブルクリックします。
3. 黒い画面（サーバー処理）が一瞬立ち上がった後、自動的に既定のWebブラウザ（Chrome/Edge等）が開き、アプリ画面が表示されます。
4. アプリ起動後、画面左側の「サイドバー」にある「Google Gemini APIキー設定」欄にご自身のAPIキーを入力してください。
5. キーを入力すると「🔑 API連携中」と表示され、AI機能（所見生成・文章校正など）が利用可能になります。

------------------------------------------------------------------------
◆ Google Gemini APIキーの取得手順（無料）
------------------------------------------------------------------------
本ソフトのAI機能を利用するには、Googleが提供する無料の「Gemini APIキー」が必要です。

【取得手順】
1. Webブラウザで「Google AI Studio」（ https://aistudio.google.com/ ）にアクセスします。
2. お使いの Google アカウント（個人のGoogleアカウント推奨）でログインします。
3. 画面上の「Create API key」（APIキーを作成）ボタンをクリックします。
4. 生成された英数字の文字列（APIキー）をコピーします。
5. 「ツナグ先生」の左サイドバーにある入力欄に貼り付けます。

※APIキーは個人ごとに管理され、費用は基本的に無料枠内で十分運用可能です。

------------------------------------------------------------------------
◆ ダウンロード・実行時の注意事項およびトラブルシューティング
------------------------------------------------------------------------
【注意事項１：Windows Defender（SmartScreen）の保護警告について】
起動時に「WindowsによってPCが保護されました」という青い画面が表示される場合があります。
これは個人開発のフリーソフト（デジタル署名未設定）で一律表示される安全装置です。ウイルスではありません。
⇒ 【対処法】画面内の「詳細情報」をクリックし、出現する「実行」ボタンをクリックしてください。

【注意事項２：セキュリティソフトの誤検知について】
一部のウイルス対策ソフトが本ソフトを誤って検知・隔離する場合があります。その際はウイルス対策ソフトの「除外設定（信頼するソフト）」に本フォルダを追加してください。

【注意事項３：アプリが起動しない・ブラウザが開かない場合】
・フォルダパスに特殊な記号が含まれていないか確認し、デスクトップ等にフォルダを移動してお試しください。
・すでに「ツナグ先生.exe」がバックグラウンドで起動している可能性があります。タスクマネージャー（Ctrl+Shift+Esc）から「ツナグ先生.exe」を終了して再起動してください。

------------------------------------------------------------------------
◆ 個人情報保護およびセキュリティ仕様（安心してお使いいただくために）
------------------------------------------------------------------------
校務における個人情報漏洩を防止するため、本ソフトには以下の強力なプロテクト機能を標準搭載しています。

1. 【入力データの完全ローカル処理】
   入力した生徒名簿、成績、観察メモ等のデータは、お客様のパソコン内（メモリ上）のみで処理され、作者の外部サーバー等に送信・保存されることは一切ありません。

2. 【AI送信時の自動仮名化（マスキング）機能】
   左サイドバーの「🔒 AI送信時の個人情報仮名化プロテクト」がONの状態でAI生成を行うと、生徒氏名（例: 山田太郎）が「生徒A」「生徒B」といった仮名に自動変換されてGoogle AIに送信されます。生成完了後にローカル上で元の氏名へ自動復元されます。
